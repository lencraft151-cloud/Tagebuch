Wie funktioniert das ohne Anmeldung bei GitHub?

Der Bereich liest die Inhalte direkt aus dem öffentlichen Repository … – dafür braucht es keinen Zugang.

Deine Änderungen bleiben zunächst in diesem Browser. Zum Veröffentlichen lädst du sie als Paket herunter und legst es einmal bei GitHub ab. Dort bist du ohnehin angemeldet, also muss hier nirgends ein Schlüssel liegen.

Die PIN ist ein Riegel gegen versehentliches Verstellen, keine Zugangssperre: Veröffentlichen kann ohnehin nur, wer Schreibrechte auf das Repository hat.

Dieser Bereich schreibt nichts ins Repository – deshalb in zwei Schritten, ganz ohne Zugangsschlüssel.

    Ein ZIP mit dem Ordner content – genau so, wie das Repository aufgebaut ist.
