Zugang einrichten

Einmalig: Lege eine PIN fest und hinterlege deinen GitHub-Token. Der Token wird mit der PIN verschlüsselt in diesem Browser gespeichert – danach reicht die PIN zum Anmelden.

Wie erstelle ich einen Token?
  1. GitHub öffnen → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate new token wählen und als Resource owner den Besitzer dieses Repositories setzen.
  3. Unter Repository access nur dieses eine Repository auswählen: …
  4. Unter Repository permissions → Contents: Read and write setzen.
  5. Token erzeugen, kopieren und hier einfügen.

Setz eine Ablaufzeit. Läuft der Token ab, richtest du den Zugang hier einfach neu ein.
